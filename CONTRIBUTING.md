# Contributing

This repo holds only the **store and app manifests** for the SBA Umbrel App
Store. There is no app source code here.

- **App bugs, feature ideas and feed requests** for BlockClock Connect belong
  in the app repo:
  [github.com/bayanimills/blockclock-connect/issues](https://github.com/bayanimills/blockclock-connect/issues)
  (there are templates for bug reports and feed requests).
- **Store problems** (the store won't add, an app won't install from it, a
  manifest error) can be raised as issues here.

Manifest changes (version bumps, release notes, gallery) normally track app
releases, so please open an issue in the app repo first rather than PRing
manifest edits directly.
